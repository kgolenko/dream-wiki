            ### ⚠️ **Увага! Важливе попередження!**
            
            ### Проект BummerRust поширює шкідливе ПЗ через свій клієнт гри. Наполегливо рекомендуємо не грати на цьому проекті, оскільки це може призвести до зараження вашого комп'ютера вірусами та втрати доступу до інших ігрових серверів.
        </Callout>

        ### Частина 1: Видалення правил брандмауера
        1. Відкрийте "Брандмауер захисника Windows" через пошук <Code color="primary">(Win + Q)</Code>
        2. Натисніть зліва "Додаткові параметри"
        3. Виберіть "Правила для вихідного підключення"
        4. Знайдіть правило "block ip...." (зазвичай знаходиться в самому верху)
        5. Виділіть усі IP-адреси:
           - Клікніть ЛКМ по першій адресі
           - Пролистайте до кінця списку
           - Затисніть <Code color="primary">SHIFT</Code> і клікніть ЛКМ по останній адресі
        6. Натисніть кнопку «Видалити»

        ### Частина 2: Видалення шкідливого файлу
        1. Натисніть <Code color="primary">Win + R</Code>
        2. Введіть команду <Code color="warning">%temp%</Code>
        3. У відкритій папці знайдіть файл <Code color="danger">dllhost32.exe</Code>
        4. Видаліть цей файл

        <Callout>**Важливо**: Файл dllhost32.exe є шкідливим і використовується для управління заблокованими IP-адресами у вашій системі</Callout>
