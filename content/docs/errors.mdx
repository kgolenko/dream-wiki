    <Accordion title={`If you played on the BummerRust project and no longer have access to the server.`}>
        <Callout type="danger">
            ### ⚠️ **Attention! Important warning!**
            
            ### The BummerRust project distributes malicious software through its game client. We strongly recommend not playing on this project, as it may infect your computer with viruses and lead to loss of access to other game servers.
        </Callout>

        ### Part 1: Removing firewall rules
        1. Open "Windows Defender Firewall" via search <Code color="primary">(Win + Q)</Code>.
        2. Click "Advanced settings" on the left.
        3. Select "Outbound Rules."
        4. Find the rule "block ip...." (usually at the top).
        5. Select all IP addresses:
           - Left-click on the first address.
           - Scroll to the end of the list.
           - Hold <Code color="primary">SHIFT</Code> and left-click the last address.
        6. Click the "Delete" button.

        ### Part 2: Removing the malicious file
        1. Press <Code color="primary">Win + R</Code>.
        2. Enter the command <Code color="warning">%temp%</Code>.
        3. In the opened folder, find the file <Code color="danger">dllhost32.exe</Code>.
        4. Delete this file.

        <Callout>**Important**: The dllhost32.exe file is malicious and used to manage blocked IP addresses in your system.</Callout>
    </Accordion>
    <Accordion title={`Skins not loading (even though they are downloaded).`}>
        1. Remove Cyrillic characters from the game folder path.
        2. Ensure your Windows username does not contain Cyrillic characters.
        3. Remove the "read-only" attribute from the game folder.
