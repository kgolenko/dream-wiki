        <Callout type="danger">
            ### ⚠️ **Внимание! Важное предупреждение!**
            
            ### Проект BummerRust распространяет вредоносное ПО через свой клиент игры. Настоятельно рекомендуем не играть на данном проекте, так как это может привести к заражению вашего компьютера вирусами и потере доступа к другим игровым серверам.
        </Callout>

        ### Часть 1: Удаление правил брандмауэра
        1. Откройте "Брандмауэр защитника Windows" через поиск <Code color="primary">(Win + Q)</Code>
        2. Нажмите слева "Дополнительные параметры"
        3. Выберите "Правила для исходящего подключения"
        4. Найдите правило "block ip...." (обычно находится в самом верху)
        5. Выделите все IP адреса:
           - Кликните ЛКМ по первому адресу
           - Пролистайте до конца списка
           - Зажмите <Code color="primary">SHIFT</Code> и кликните ЛКМ по последнему адресу
        6. Нажмите кнопку «Удалить»

        ### Часть 2: Удаление вредоносного файла
        1. Нажмите <Code color="primary">Win + R</Code>
        2. Введите команду <Code color="warning">%temp%</Code>
        3. В открывшейся папке найдите файл <Code color="danger">dllhost32.exe</Code>
        4. Удалите этот файл

        <Callout>**Важно**: Файл dllhost32.exe является вредоносным и используется для управления заблокированными IP-адресами в вашей системе</Callout>
    </Accordion>
