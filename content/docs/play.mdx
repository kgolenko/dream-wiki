    In order to download the game, you need to use WinRar or 7zip.

  </div>
  <div className="step">
    ### Launch the game

    <Callout>Don't forget to launch Steam</Callout>

    Go to the game folder and run <Code color="success">Dream.exe</Code>

    In the opened window, click on the gear

    <ImageCard imageUrl="https://s3.dreamrusttop.ru/dream/images/launcher_start.png" width={100} height={200} />

    Select the path to the game

    <ImageCard imageUrl="https://s3.dreamrusttop.ru/dream/images/launcher_settings.png" width={100} height={200} />

    The path should be something like this: (this is an example, your path may be different)
    <ImageCard imageUrl="https://s3.dreamrusttop.ru/dream/images/launcher_path.png" width={1200} height={150} />

    Click on the Green Circle button and wait for the game files to be checked, after that the game will start

    <ImageCard imageUrl="https://s3.dreamrusttop.ru/dream/images/launcher_load.png" width={100} height={200} />
  </div>
